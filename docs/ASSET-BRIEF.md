# ASSET-BRIEF — artwork export and generation

For Sam (Photoshop + ChatGPT) and for whoever wires the art into the app. File names below are **contracts**: code references them; if a true layer isn't available, ship a fallback crop under the same name and swap later with no code change.

Ground rules: the PSD never leaves `SBG Content/` and is never committed. Everything exported here is a derivative for app use only. Official lockups and the SBG logo are used unmodified. Nothing generated depicts musicians, real people, the wordmark, or the logo.

---

## 1. Poster layer export (Photoshop → `apps/festival/public/art/`)

**Canvas math.** The poster is 16×28 in; the flattened preview is 1080×1890. Export at **2× that: 2160×3780 px**, full canvas, PNG-24 with transparency, sRGB, no interlace. Every layer file shares the same canvas so the app stacks them with plain absolute positioning. (Photoshop: *Image Size* to 2160 wide with Preserve Details 2.0 on a duplicate document, then *File → Export → Export As* per group with "Transparency" on; or *Layers → Export Layers to Files* on the merged groups.)

| # | File | What to include (merge these poster groups) | Notes |
|---|---|---|---|
| 0 | `paper.png` | paper texture only, no border, no art | flatten to opaque; we tile a 512 px crop from it as `paper-tile.png` for grain |
| 1 | `checker-border.png` | the checkerboard frame | transparent center; we also need `checker-tile.png` (one repeating unit, ~64×64 at 2×) |
| 2 | `sky.png` | sky gradient + clouds + stars field inside the arch | opaque within the arch, transparent outside |
| 3 | `rays.png` | sun disc + radiating rays (+ the rainbow arch stripes if they're on the same layer; if separable, put rainbow in `arch.png`) | transparent elsewhere; rays are rotated by code |
| 4 | `arch.png` | rainbow arch bands + the arch's checker inner ring | optional if inseparable from #3 |
| 5 | `mountains-far.png` | back mountain range + snow caps | |

Also export, cropped to bounds at 2×: `columbine.png` (one flower), `cloud.png` (one cloud), `star.png` (one star from the sky), `pine.png` (one tree). These become chips, badges, empty-state props, and the favorite "bloom."

**Fallback if layers won't separate cleanly:** export the fully flattened poster at 2160×3780 as `poster-flat.png`; the app will use masked crops (sky region, mountain band, foreground band) under the same file names. Do this first — it's five minutes — so Day 1 has *something*.

**Delivery check:** open each PNG on a checkerboard background to confirm alpha; total for #0–#12 should land under ~12 MB at 2×; the build converts to WebP (lossless alpha) and generates 1× variants.

## 3. ChatGPT-generated supporting art (transparent PNGs, `apps/festival/public/art/gen/`)

Use only where a true poster layer doesn't exist. Every prompt must end with the style block and the exclusions below. Generate at 2048 px square or wider, request **transparent background**, review for stray text/letters (the models love adding words), and reject anything that reads as a different art style.

**Style block (paste into every prompt):**
> Style: 1970s psychedelic concert-poster illustration in the manner of a screen-printed music festival poster; thick warm-black ink outlines; flat, saturated fills with subtle halftone grain; slightly imperfect hand-drawn shapes; palette limited to cream paper #EAD6BA, warm black #201C1D, sky teal #158EAA, night blue #173A65, sun yellow #E8C146, amber #D1973D, ember red #C8413F, pine green #1B8D5F, leaf green #54AF65, plum #69155C, violet #7A3E8E, bloom pink #E0508F. Transparent background, isolated object, centered, no drop shadow.
> Exclude: any text, letters, numbers, logos, watermarks, people, faces, musicians, instruments being played, photorealism, 3D render, gradients that look digital, neon glow.

Not generated, ever: the wordmark, the SBG logo, artist portraits, band photos, anything the store could read as depicting a real performer.

## 4. Vector icons (made in code, not generated)

Tab bar and UI icons are inline SVG drawn by Claude Code on a 24 px grid, 2 px stroke, rounded caps, with filled variants for the active tab: Now (sun with rays), Lineup (three stacked horizontal bars with a note), Plan (calendar with a heart), Alerts (bell with a small ray), Info (circle-i). Match SF Symbols weights on iOS (medium) and Material Symbols on Android (rounded). No icon fonts.

## 5. Fonts (download from Google Fonts / GitHub, commit under `apps/festival/public/fonts/` with their OFL.txt)

Bungee (Regular), Bungee Shade (Regular), Michroma (Regular), DM Sans (variable, wght 400–700 + italic optional). Record exact sources and license text in `docs/FONT_LICENSES.md`.
